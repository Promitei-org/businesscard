# Promitei business card page

Published with GitHub Pages at **https://promitei-org.github.io/businesscard/**. The QR code on the printed Promitei business cards opens this page.

## What is on the page
- Logos of Promitei Ltd. and Promitei Data, the torch, "Passing the torch of technology", key facts.
- Buttons with logos: LinkedIn, Promitei Ltd., Promitei Data, TechGuard Labs Foundation, Promitei Energy, contact form; WhatsApp and email.
- Team: Lemuel Melamed and Mark Melamed with phones, email and "Save contact" (`lemuel-melamed.vcf`, `mark-melamed.vcf`).
- Services (links to promitei.com) and offices with map links.

To change where a button leads, edit its `href` in `index.html`. The printed QR code keeps working as long as the page stays at this address.

Promitei Energy currently links to https://promitei.com/sectors#energy because promitei-energy.com has an expired TLS certificate; switch it back once the certificate is renewed (see the comment in `index.html`).

GitHub Pages settings: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.

Fonts, torch images and logos are copies from promitei.com; `icon-*.png` are the emblems cut from those logos.
